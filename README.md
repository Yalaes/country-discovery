# Country Discovery

A study project built to practice web development with JavaScript.

## About

Country Discovery is a small project focused on exploring country data through an API and displaying information such as flags, capitals, regions, currencies, languages, time zones, and population.

## Goals

- Practice JavaScript and ES modules
- Fetch and process data from an API
- Work with arrays and objects
- Handle missing or unexpected data
- Learn unit testing with Vitest

## Technologies

- HTML
- CSS
- JavaScript
- [Countries.dev API](https://countries.dev/docs)
- [Vitest](https://vitest.dev/)

## Status

This project is for learning and experimentation. It is not intended as a production application.
